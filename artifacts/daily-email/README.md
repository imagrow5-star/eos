# Eos — Daily Email Job

A one-shot Node.js script that sends personalized morning notes to all eligible Eos users.

## How it works

- **Runs as a Replit Scheduled Deployment** (separate from the main API server deployment)
- Cron: `0 * * * *` — every hour on the hour
- Each run checks every user's local time and only sends emails to users whose clock shows **6–9 AM** in their timezone
- Skips users who have already received an email today, opted out, or have no personal data yet

## Deploying

1. **Build** the script locally to verify it compiles:
   ```
   pnpm --filter @workspace/daily-email run build
   ```

2. **In the Replit Publishing panel**, create a new deployment:
   - Deployment type: **Scheduled**
   - Build command: `pnpm --filter @workspace/daily-email run build`
   - Run command: `node --enable-source-maps artifacts/daily-email/dist/index.mjs`
   - Cron schedule: `0 * * * *`

3. **Environment variables** — the scheduled deployment needs the same secrets as the API Server:
   - `DATABASE_URL`
   - `ANTHROPIC_API_KEY`
   - `RESEND_API_KEY`
   - `RESEND_FROM_EMAIL`
   - `SESSION_SECRET`
   - `APP_URL` (optional — defaults to `https://eoscompanion.com`)

## Local test run

```
pnpm --filter @workspace/daily-email run dev
```

This runs the script once immediately. It will skip most users (not in 6–9 AM window)
but will log the user count and any errors.

## Email design

- **Intimate Dusk** dark theme (`#1B1922` background, `#C79A5B` gold, `#EFE6D6` cream text)
- Generated by Claude claude-sonnet-4-5 at `temperature: 0.8` — warm and varied, never flat
- Prompt is anti-cliché by design: references real habits, wins, and memory facts
- 4–7 sentences, ends with one specific nudge tied to the user's actual life
- One-click unsubscribe via `GET /api/email/unsubscribe?uid=X&token=T` (HMAC-signed)

## Opt-out

Users can unsubscribe via the link in every email footer. The link calls
`/api/email/unsubscribe` on the main API server and sets `daily_email_opt_out = true`
on their profile. No re-opt-in is provided in the UI yet (future task).
