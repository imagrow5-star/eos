## Growth score formula
Computed dynamically in `artifacts/api-server/src/routes/journey.ts`, never stored in DB.

```
raw = totalHabitCompletions × 2 + winCount × 3 + moodDayCount × 1
growthScore = raw === 0 ? 1 : min(99, round(1 + (raw / (raw + 40)) × 98))
```

- S-curve: starts at 1%, approaches 99% asymptotically — always has room to grow, never punitive.
- Never decreases — missed days just pause it.

## Habit-mood insight
`computeHabitMoodInsight()` in journey route loops through each active habit, compares avg mood on days completed vs not completed, returns a one-liner for the habit with the clearest correlation (diff > 0.5). Falls back to null if < 4 mood entries.

## API schema
Fields added to `GetJourneyResponse` in `lib/api-zod/src/generated/api.ts`:
- `growthScore: zod.number()`
- `habitMoodInsight: zod.string().nullish()`

These are in the **generated** file (not auto-generated by a script), so they persist across sessions.

## Journey.tsx casting
Because the generated React Query hook types lag the zod schema, access new fields via cast:
```tsx
const growthScore = (journey as any).growthScore as number ?? 1;
const habitMoodInsight = (journey as any).habitMoodInsight as string | null ?? null;
```

**Why:** The React Query hooks are code-generated from an OpenAPI spec that wasn't regenerated. Rather than regenerate, a cast is cleaner and avoids breaking the codegen pipeline.
